# 江西矿山生态修复智能监测平台 HTML 使用说明书设计

## 1. 目标与读者

为当前江西正式交付环境制作一份中文、可离线打开的 HTML 使用说明书。主要读者是日常业务人员，次要读者是负责启动、验收和恢复服务的管理员。内容以当前 GPU standalone 运行基线为准，不把 CPU 运行流程、云南项目流程或旧 `mine_fid` 业务关联写入新手册。

说明书的单一任务是让读者能够从登录开始，完成矿山检索、项目管理、ROI 推理、地物分类、光谱指数和结果查看，并在服务异常时进行有限、可回滚的管理员处置。

## 2. 当前运行基线

- 运行容器：`geoview-jiangxi-gpu`
- 稳定镜像：`geoview-jiangxi:jiangxi-gpu`
- 当前验收镜像：`geoview-jiangxi:jiangxi-gpu-20260829-square512`
- 设备：`cuda:0`，当前硬件为 NVIDIA GeForce RTX 5060
- 公共入口：地图 `http://127.0.0.1:4173/#/map`、解译平台 `http://127.0.0.1:4174/#/segmentation`、后端 `http://127.0.0.1:5178`；江西健康检查由 Miner 服务提供，地址为 `http://127.0.0.1:4173/api/health/jiangxi`。
- 权威资产：Excel、SHP（含 SHX/DBF/PRJ）、KMZ，共 348 条；业务主键为 `TBBH`，`map_fid` 仅为地图与历史目录技术编号。
- 持久化卷：`jiangxi-runtime-gpu-f-20260829c` 挂载到 `/app/runtime_data`。

手册中的健康标准固定为：服务健康、348 条矿山、348 个唯一 TBBH、资产 manifest 哈希一致、GPU Worker 已就绪。任何推理示例都必须标为“示例结果”，不得声称其等同于精度评测或真值标注。

## 3. 交付物与文件边界

交付目录为 `docs/manual/`：

- `docs/manual/index.html`：唯一入口，直接双击即可在现代浏览器离线查看。
- `docs/manual/assets/`：手册专用的本地截图与标注图；HTML 只能引用此目录的相对路径，不使用网络图片、CDN、在线字体或外部脚本。
- `docs/user_manual.md`：替换为简短的迁移页，说明当前正式手册为 `docs/manual/index.html`，并删除旧 CPU 操作步骤，避免两份说明给出相互冲突的运行口径。

不修改业务前端、后端、模型、Docker 镜像、数据卷或管理员凭据。截图中不得保留密码、密钥、令牌、绝对用户目录或敏感运行日志。

## 4. 信息架构

HTML 使用固定左侧导航、正文阅读区和顶部“当前交付基线”状态带。正文按以下顺序组织：

1. 快速开始：入口、登录前检查、当前 GPU 状态和角色分工。
2. 登录与安全：管理员账号来源、两个前端的共享会话、重新登录和退出行为。
3. 矿山地图：统计概览、筛选、按 TBBH/名称/地图编号检索、定位、图斑详情、生态诊断与趋势。
4. 项目工作台：新建/编辑项目、绑定矿山、管理数据集、查看时间线、导出 GeoJSON/CSV/SHP、生成备份和恢复备份。
5. ROI 推理：输入 KML、影像路径、单年/双年年份参数、提交任务、结果目录、失败提示和结果读取。
6. 地物分类：选择数据源、设置参数、执行 GPU 推理、读取六类图例、查看和下载结果。
7. 光谱指数：选择影像、设置指数、年份与 TBBH、执行计算、读取预览和历史结果。
8. 结果判读：区分原始影像、分类结果、ROI 边界和道路类别；说明模型输出必须结合人工复核。
9. 管理员维护：启动/停止的安全边界、健康检查、资产校验、GPU Worker 状态、日志定位、容器回退。
10. 常见问题与术语：登录失效、图层/结果加载失败、TBBH 不存在、无历史结果、映射缺失、数据损坏和词汇对照。

每个业务章节使用同一结构：**何时使用 → 前置条件 → 操作步骤 → 成功标志 → 注意事项/失败处理**。涉及破坏性或可能影响运行数据的操作，仅出现在管理员章节并标注“管理员操作”。

## 5. 截图与图示策略

采用真实的江西界面截图，并在副本上叠加编号、红框和简短标注。第一版至少包括：

- 登录页：账号输入、登录、会话失效提示。
- 监测地图工作台：地图、筛选栏、统计栏、解译入口和项目入口。
- 项目工作台：项目列表、图斑绑定、数据集、导出与备份区域。
- 解译平台：地物分类的结果预览；数据源、参数设置和执行按钮以可检索的图文步骤说明。
- ROI 或结果说明：用可检索的 HTML/SVG 示意图说明原始影像、分类图、六类图例和 ROI 边界的区别。

优先从已确认的江西素材中选择 `材料/主界面.png`、当前登录页及当前已验收界面截图。项目工作台和解译平台属于长滚动页面时，使用同一页面的两张原始视口图分别说明“顶部操作”和“下方导出/预览”，不要求一张长图塞入全部控件，也不拼接或伪造界面。每张图在导入前核对是否为江西界面、是否与当前功能一致；不使用云南目录、过期 CPU 页面或含错误运行状态的截图。若现有素材不足，手册以文字步骤和流程图补足，不伪造页面截图。

图片支持点击放大，并提供替代文本和编号图注。流程图用 HTML/CSS/SVG 绘制，避免把文字嵌入难以检索的位图。

## 6. 视觉与交互

页面采用“现场工作指南”风格：浅色阅读底、深青绿标题和项目生态图例色作为有限强调色。视觉语言来源于当前江西平台，但不复制深色地图页面作为长文背景。

- 左侧目录在桌面端固定，在窄屏自动收起为目录按钮。
- 当前章节高亮并显示阅读进度。
- 操作步骤以编号卡片呈现，命令使用可复制代码块。
- 图片点击进入遮罩放大，Esc、点击遮罩和关闭按钮均可退出。
- 管理员告警、成功标志、禁止事项使用不同且有文字标签的颜色，不能只依赖颜色传达含义。
- 通过 `prefers-reduced-motion` 降低动画；`@media print` 隐藏导航和交互控件，保留目录、图注和分页规则。

## 7. 准确性与安全约束

- 只写经当前代码、运行配置或验收结果证实的功能；旧 `docs/user_manual.md` 中与 GPU 现状冲突的 CPU 说明不得复用。
- 不写出真实管理员密码、`SECRET_KEY`、MySQL 密码、token 或本机私有路径。
- 把 `TBBH` 描述为业务身份；只有在地图定位或历史输出目录情境下说明 `map_fid`。
- API 的 401 登录保护、TBBH 不存在、无历史结果、映射缺失和文件损坏需要给出不同的用户可见处理办法。
- 不提供删除镜像、删除卷、清空数据库或直接修改模型权重的常规操作步骤。

## 8. 验收标准

1. 在断开网络的本机浏览器中打开 `docs/manual/index.html`，页面样式、导航、图片、放大和锚点均可用。
2. 所有图片均为本地相对路径，文件存在且具有中文替代文本；不存在外部 `http(s)` 资源依赖。
3. 目录覆盖第 4 节列出的十类功能；每个业务章节都有前置条件、步骤、成功标志和注意事项。
4. 管理员章节只使用当前 GPU 实例、稳定镜像、持久化卷、348 条资产和健康检查的真实口径。
5. 静态校验可发现丢失图片、重复锚点、无效内部链接、外部依赖、敏感字面值和遗留 CPU 操作命令。
6. 在桌面和窄屏宽度下人工检查排版；打印预览中不出现被导航遮挡的正文或断裂的截图。

## 9. 不在本次范围内

- 重写应用 UI、修改业务逻辑或调整推理模型。
- 删除 CPU 镜像、旧容器、运行数据卷或其它仓库文件。
- 把手册接入在线 CMS、数据库或权限系统。
- 对模型精度作量化承诺或生成未经验证的精度结论。

# 矿山生态修复智能监测平台用户手册设计

## 目标与用途

生成一份用于软件著作权申请的《矿山生态修复智能监测平台用户手册》，输出文件为 `D:\项目\JiangXi\用户手册.docx`。手册以当前江西独立工程实现的功能为事实依据，但封面、标题和正文的产品名称统一使用“矿山生态修复智能监测平台”，不添加省级名称。

## 读者与边界

读者为软著审查或材料整理人员，以及可按说明使用系统的普通业务用户。文档证明软件具有完整、可操作的功能界面和业务流程；不包含部署口令、数据库凭据、容器编排细节、接口地址或模型训练实现。

现有截图保持原样，不裁改页面中的实际地区、账号或功能文字。截图图注使用中性表述，例如“系统登录界面”“治理状态查询界面”，避免使封面软件名称与实际界面文字产生不必要的冲突。

## 内容结构

1. 封面：软件名称、文档名称、版本与编制日期。
2. 修订说明与目录：说明文档用途、适用对象和章节导航。
3. 软件概述：软件定位、业务目标、主要能力和运行环境。
4. 快速开始：登录、界面区域说明、退出登录。
5. 地图监测与查询：主界面、图斑查询、基础资料、所属地市、治理状态。
6. 生态修复分析：气候背景、恢复诊断和模型研判。
7. 遥感指数分析：NDVI、FCV、LAI、LST、NPP、TVDI 图层的查看与判读。
8. 使用说明：常见操作提示、数据查看建议和常见问题。

每一项核心功能采用“功能说明—操作步骤—界面说明—结果与提示”结构；由此使操作和对应界面证据相邻出现。

## 视觉与排版

采用正式、克制的申报材料风格：A4 纵向、蓝灰色标题层级、清晰的章节编号、页眉页脚和连续页码。封面为简洁标题页；正文使用可读性优先的段落、编号步骤、提示框和少量信息表。避免以大段文字替代界面或堆叠技术术语。

## 质量验证

生成后必须：

1. 对照源码、项目说明和素材名称检查功能表述，不添加尚未实现的能力；
2. 检查全部 14 张截图均已嵌入并有图题；
3. 使用 Word 渲染工具导出页面 PNG，逐页检查中文字体、截图清晰度、页码、段落、表格及图片是否存在截断、重叠或空白页；
4. 在确认最终文件后，仅交付 `D:\项目\JiangXi\用户手册.docx`。

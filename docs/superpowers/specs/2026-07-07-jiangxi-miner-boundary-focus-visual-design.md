# 江西 Miner 地图边界聚焦与矿山高亮设计

## 1. 背景

当前江西 Miner 地图页虽然已恢复主界面渲染，但地图视觉焦点仍不足：

- 地图缺少江西省行政边界轮廓，用户进入页面后无法一眼建立“当前聚焦江西”的空间认知。
- 矿山图斑虽然已经可见，但边界表现力不强，在深色底图上不够醒目。
- 当前地图主要依赖图斑本身 fitBounds，缺少“省域边界 + 省外弱化”的区域聚焦体验。

本轮改造目标是补齐“江西省边界聚焦 + 矿山边界高亮”这一层视觉表达，在不改变现有业务统计口径的前提下，提升地图识别效率和空间感知质量。

## 2. 目标

本轮目标：

- 在地图页叠加真实的江西省一级行政边界。
- 通过省外弱化遮罩形成“江西省内聚焦”的视觉效果。
- 提升矿山图斑边界的视觉识别度，使其在底图上更醒目。
- 保持底图、江西边界、矿山图斑三者可同时理解，不互相遮蔽。
- 在边界数据加载失败时保持地图主流程可用，不影响图斑显示。

非目标：

- 不调整 `/api/stats` 和现有看板统计口径。
- 不扩展到江西各地市行政边界下钻。
- 不新增新的地图业务筛选维度。
- 不将行政边界接入为运行时外部 API 依赖。

## 3. 设计方案

### 3.1 地图层级

地图渲染层级调整为：

1. 底图层
2. 江西省聚焦层
3. 矿山图斑层
4. 交互提示层

其中江西省聚焦层包含两部分：

- 江西省轮廓线
- 江西省外弱化遮罩

渲染顺序要求：

- 先渲染底图，再渲染江西省聚焦层，最后渲染矿山图斑。
- 省外弱化遮罩不能盖住江西省内图斑。
- 江西省轮廓线必须在底图之上、图斑之下或与图斑边界错层呈现，避免互相抢主视觉。

### 3.2 聚焦规则

首次进入地图页时：

- 若江西省边界加载成功，优先按江西省边界 `fitBounds`。
- 若江西省边界加载失败，但图斑可用，则回退为图斑范围 `fitBounds`。

后续交互规则：

- 用户进行缩放、拖拽、筛选后，不自动强制拉回全省视角。
- 仅在首次加载或执行“重置”时恢复江西省聚焦视角。

### 3.3 江西省边界视觉规则

江西省行政边界使用真实公开边界数据，固化到项目内部。

视觉表现：

- 江西省轮廓线：高亮青蓝描边
- 省外区域：深色半透明弱化遮罩
- 江西省内区域：保持底图可见，不额外覆深色面

目标效果：

- 用户进入地图页后能直接理解“当前地图聚焦江西省”
- 省外信息退居次要，不干扰矿山识别

### 3.4 矿山图斑视觉规则

矿山图斑采用“青蓝科技感”强化方案。

表达原则：

- 填充层保留治理状态差异，但降低填充存在感
- 边界层作为主识别元素，提升亮度、线宽和对比度

建议颜色口径：

- 已治理：亮青绿边界
- 未治理：亮橙红边界
- 未知/其他：亮蓝灰边界

交互规则：

- 默认：边界已明显强于当前版本
- 悬停：线宽进一步增粗，亮度提升
- 选中：使用最高亮度高亮边界，明确区分于普通悬停态

图例同步更新：

- 继续保留治理状态说明
- 但需要体现“边界高亮为主、填充为辅”的新视觉逻辑

### 3.5 边界数据接入方式

边界数据来源采用公开江西省行政边界文件，经确认后下载并固化到项目内。

接入原则：

- 不在运行时请求第三方边界接口
- 使用静态文件由前端只读加载
- 本轮只接入“江西省一级行政边界”，不接入地市级边界

边界数据需满足：

- 格式可被前端 Leaflet 直接消费（优先 GeoJSON）
- 坐标系可与当前地图显示链路兼容
- 文件体积适中，不显著拖慢地图加载

## 4. 错误态与回退策略

### 4.1 边界失败

若江西省边界文件缺失、损坏或解析失败：

- 不阻塞地图页主流程
- 继续显示底图和矿山图斑
- 地图聚焦回退为图斑范围
- 状态提示为：`江西省边界加载失败，已回退到图斑范围聚焦`

### 4.2 底图失败

若在线底图失败：

- 保留江西省边界和矿山图斑
- 按现有底图回退机制继续处理
- 状态提示中需能体现边界与图斑仍可用

### 4.3 图斑失败

若图斑加载失败但边界成功：

- 仍展示江西省边界和聚焦遮罩
- 提示用户当前处于江西省范围，但图斑数据失败

### 4.4 禁止出现的问题

- 不能因为边界数据异常导致整页黑屏
- 不能因为边界遮罩导致江西省内图斑不可见
- 不能因为高亮边界导致底图完全失去可读性

## 5. 实施范围

本轮只修改地图可视化相关链路，范围控制在：

- 地图组件的边界层加载与渲染
- 地图聚焦与 `fitBounds` 逻辑
- 矿山图斑样式定义
- 地图状态提示文案
- 静态江西边界数据文件接入
- 图斑详情弹窗的年度生态指标接入与标签重组

不包含：

- 右侧统计图表逻辑
- 后端统计服务

## 6. 弹窗年度生态指标接入

### 6.1 数据来源

本轮接入 `348图斑_TableMERNet无图像预测结果.xlsx` 中真实存在的年度生态指标列。

经核查，该文件包含以下按“指标前缀 + 年份”展开的生态核心指标：

- `NDVI_2013~2025`
- `FCV_2013~2025`
- `LAI_2013~2025`
- `NPP_2013~2025`
- `LST_2013~2025`
- `SM_proxy_2013~2025`
- `TVDI_proxy_2013~2025`

本轮不将以下指标纳入主弹窗：

- `mean_temp_C_*`
- `total_precip_mm_*`

原因：

- 与矿山生态恢复主题相比，这两类气象指标不是当前主视角；
- 若全部纳入会显著增加弹窗复杂度，削弱主信息密度。

### 6.2 数据解析规则

接入方式采用“按前缀自动识别 + 按年份聚合”的规则。

规则如下：

- 列名如 `NDVI_2018` 解析为：指标名 `NDVI`，年份 `2018`
- 同一指标的所有年份列组装成一条时序序列
- 展示时按年份升序排列

图斑与 Excel 行数据匹配规则：

- 优先使用 Excel 中的 `FID` 与当前图斑的 `FID_1` 对齐
- 若实现阶段发现存在不一致，再单独补充第二匹配键策略；本轮设计不预设不确定兜底逻辑

### 6.3 弹窗展示规则

详情弹窗继续保持“基础信息优先”原则。

展示结构调整为：

- 保留：`基础信息`
- 保留：`变化矩阵`
- 保留：`地物分类`
- 新增真实年度生态指标标签：
  - `NDVI`
  - `FCV`
  - `LAI`
  - `NPP`
  - `LST`
  - `土壤湿度代理`
  - `干旱指数代理`

每个指标标签页展示内容：

- 年度折线图
- 均值
- 起止年份
- 可选趋势判断

### 6.4 与现有弹窗分析项的关系

当前弹窗中已有：

- `NDVI`
- `NDBI`
- `NDWI`
- `NDSI`
- `变化矩阵`
- `地物分类`

本轮规则：

- 真实 Excel 指标优先级高于当前没有明确来源保证的旧分析项
- 没有来自该 Excel 支撑的数据项，不再强行保留在主标签位

因此调整方向为：

- 保留：`基础信息`、`变化矩阵`、`地物分类`
- 用真实年度生态指标替换没有稳定数据支撑的主分析标签

### 6.5 缺失值规则

若某图斑的某项年度生态指标不存在：

- 可以保留该指标标签页
- 页面明确显示：`暂无该图斑年度数据`
- 严禁使用 `0` 伪装为真实值

## 7. 错误态与回退策略

### 7.1 边界失败

若江西省边界文件缺失、损坏或解析失败：

- 不阻塞地图页主流程
- 继续显示底图和矿山图斑
- 地图聚焦回退为图斑范围
- 状态提示为：`江西省边界加载失败，已回退到图斑范围聚焦`

### 7.2 底图失败

若在线底图失败：

- 保留江西省边界和矿山图斑
- 按现有底图回退机制继续处理
- 状态提示中需能体现边界与图斑仍可用

### 7.3 图斑失败

若图斑加载失败但边界成功：

- 仍展示江西省边界和聚焦遮罩
- 提示用户当前处于江西省范围，但图斑数据失败

### 7.4 年度生态指标失败

若 Excel 未加载成功、字段解析失败或指定图斑未匹配到年度记录：

- 不影响基础信息、边界层、图斑层和变化矩阵主流程
- 仅在对应指标标签页显示缺失提示
- 不出现整弹窗空白或整体报错

### 7.5 禁止出现的问题

- 不能因为边界数据异常导致整页黑屏
- 不能因为边界遮罩导致江西省内图斑不可见
- 不能因为高亮边界导致底图完全失去可读性
- 不能因为 Excel 指标解析失败导致详情弹窗整体不可用

## 8. 验收标准

验收通过需满足以下条件：

1. 首次进入地图页时可见江西省矢量边界。
2. 江西省外区域被明显弱化，视觉焦点落在江西省内。
3. 矿山图斑边界比现状更醒目，且悬停/选中态有明确差异。
4. 边界文件异常时，地图仍能显示图斑并给出明确提示。
5. 不再出现因边界层异常导致的整页黑屏或主结构不渲染。
6. 单镜像运行状态下，页面刷新后仍能稳定进入地图页并显示江西聚焦效果。
7. 点击图斑后可看到来自 Excel 的真实年度生态指标标签与年度曲线。
8. 指标缺失时仅显示当前指标缺失提示，不影响弹窗其他内容。

## 9. 验证方式

完成实现后至少执行以下验证：

- 前端构建验证
- 单镜像重建与重启验证
- 浏览器进入地图页后的可见性验证
- 边界文件存在时的正常路径验证
- 人工制造边界加载失败时的回退路径验证
- Excel 指标存在时的正常路径验证
- 图斑无匹配年度指标时的缺失提示验证

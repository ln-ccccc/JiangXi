# 图斑生态指标图表体验设计

## 目标

让矿山弹窗只呈现所有图斑均可用的分析项，并以清晰的趋势图展示工作簿生态指标。

## 已确认的设计

- 移除“变化矩阵”和“地物分类”：当前交付没有任何图斑的矩阵输出或分类图像。
- NDVI、FCV、LAI、NPP、LST、土壤湿度和 TVDI 的图表默认按两年采样显示；用户可切换为逐年采样。
- 图表采样只影响折线的显示点，原始年度值与缺失年份仍完整保留，绝不插值。
- 页签栏保持两行横向滚动，轨道透明、滑块半透明青绿色。
- 气候背景仍是温度折线与降水柱状的双轴图，不加入本次采样切换。

## 根因

`EcologyDiagnosisPanels.vue` 中的趋势图通过运行时组件创建；该组件的 DOM 元素不匹配 SFC 的 `scoped` 样式选择器，`.eco-chart` 的高度没有生效，导致 ECharts 容器高度为零。修复必须将图表高度作为运行时元素样式提供。

## 验收

- 弹窗不再出现变化矩阵或地物分类页签，也不再请求变化矩阵数据。
- FCV 等指标页显示可见折线；默认年份为 2013、2015、2017、2019、2021、2023、2025。
- 切换逐年后显示全部有效年份；原始年度表仍完整。
- 滚动轨道不显示默认白色滚动条。
